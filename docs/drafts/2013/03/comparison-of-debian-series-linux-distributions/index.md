The Debian series Linux
(including Debian, Ubuntu, Mint, antiX, etc) is a popular Linux distribution series.
It is a good choice for personal (desktop) use.
The following are some comparisons based on my PERSONAL experience.

1. Ease to install: Ubuntu = Mint >> Debian.

1. Usability: Ubuntu = Mint > Debian.

1. Stability: Debian > Mint >= Ubuntu.

1. Performance: Debian > Ubuntu, Mint

1. antiX is lightweighted Debian compatible Linux distribution.

1. Ubuntu has more commercial, graphics related packages,
   and these packages make Ubuntu more user friendly.

1. Xubuntu (Ubuntu + Xfce) (preferable LTS) is sweet.

1. Linux distribution are based on the same kernel.
   Choosing a good desktop environment is more important than choose a Linux distribution.

1. Debian is not user friendly but it's very stable compared to Ubuntu.
   I think Linux Mint Debian Edition (LMDE) with either Mate or Cinnamon
   is a very good choice for daily use.
   First, it's totally based on Debian (testing), so it's very stable.
   Second, it's very user friendly.
   And it's rolling release.

1. I recommend to choose one among LMDE, Xubuntu and Ubuntu.

Distributions:

1. ubuntu is much simpler than other Linux distributions, very fancy.
   I like it honest speaking.
   The only thing I'm worrying about is stability. I might switch back to ubuntu in future.

1. Ubuntu, Mint and Fedora are easy to install and use.

1. Debian have more strict selection on "free" software.

1. ArchLinux is for geek.

1. Handy Linux is a Debian and Xfce-based Linux distribution,
   not good as advertised.
