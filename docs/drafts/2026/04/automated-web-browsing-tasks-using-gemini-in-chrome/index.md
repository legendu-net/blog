## Tips and Traps

1. For complicated, multi-step web automation workflows, **[BrowserOS](https://github.com/browseros-ai/browseros) (`browseros-neo`) is a much better choice than Gemini in Chrome**.
   Unlike Gemini in Chrome (which is bound to an active sidebar tab, requires a Google AI Pro/Ultra subscription for Auto Browse, has only experimental Linux support, and cannot save files to disk), BrowserOS neo runs natively on Linux and macOS with your existing logins, executes multi-step task flows in the background without stealing tab focus, batches multi-step navigation via its `run` MCP tool in seconds, supports direct file downloads/uploads, and works with any local or BYOK LLM as well as standard `SKILL.md` skills.
   For a detailed architectural comparison of BrowserOS neo, `chrome-devtools-mcp`, Gemini in Chrome, Claude Computer Use, and Perplexity Comet, see [](#ai-browsers-and-agentic-web-automation) and [](#web-automation).

1. Gemini in Chrome is not available on Linux currently!
   For more discussions,
   please refer to
   [Gemini in Chrome, for Linux](https://support.google.com/gemini/thread/412505429/gemini-in-chrome-for-linux?hl=en)
   .

1. Gemini Auto Browse introduces new features such as

   - Actionable Automation: It can automatically click, search, compare options, and add items to carts, reducing manual, repetitive tasks.
   - Cross-App Integration: Integrates with Gmail, Calendar, and Maps to gather context for tasks, such as planning trips or finding locations.
   - Security & Control: It requires user permission for sensitive actions, such as logging into accounts (using Google Password Manager) or completing purchases.
   - User Interface: A dedicated Gemini icon in the Chrome browser bar activates the tool, providing a permanent sidebar for interactions.
     However,
     Auto Browse **requires a subscription of Google AI Pro** or Google AI Ultra.

Gemini in Chrome cannot save files on to computers currently (due to security concerns),
so manual intervention (to download pages) is needed.
Still, it's a great help.

> There are links with the name patter mm/dd/yyyy in the "Pay History" table on this page. For each of those links, click into it. Wait for a few seconds for the page to finish loading, and then save that page has a single file html (mhtml). You can directly save html or mhtml files into the directory /Users/dclong/Downloads without asking for my permissions. However, make sure to save each file using different names. Once a web page is saved, click the "back" button (with a left arrow above it) to come back to this "Pay History" page and continue to the next link as those links are dynamically generated by JavaScript code. If you are unable to save files to the computer, ask for my help to download files and you can help with the auto navigation.
