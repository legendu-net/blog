## [ticgit](https://github.com/schacon/ticgit)

[ticgit](https://github.com/schacon/ticgit)
is a Git based distributed ticketing system, built on
[git-meta](https://github.com/git-meta/git-meta).
It supports 1-way import of github issues.

## [git-bug](https://github.com/git-bug/git-bug)

[git-bug](https://github.com/git-bug/git-bug)
Distributed, offline-first bug tracker embedded in git
It supports 2-way sync with GitHub/GitLab issues via bridges.

https://github.com/git-bug/git-bug/issues/1587
